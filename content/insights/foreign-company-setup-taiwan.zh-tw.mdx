## TL;DR — 外商在台灣設公司一段話講完

外商在台灣設立公司是一個六步驟的法定流程：公司名稱預查、FIA（外國人投資申請）送件、資本匯入、會計師資本簽證、經濟部公司登記、國稅局稅務登記 — 後續再加銀行開戶與（平行進行的）工作證申請。實務端到端時程是 **10–12 週**從啟動到法人完整可運作、創辦人手上有工作證。最慢的關卡是母國端文件公證（東西抵台前要 2–4 週）與外籍董事銀行 KYC（公司登記後 2–6 週）。最快的路徑是在 FIA 送件**之前**就把策略、資本額、業務範圍定好 — 因為送件後改任何一項都意味著母國再公證一次。

## 你到底要設什麼

任何文件動作開始之前，先決定三種法人型態裡你要設哪一種。這個決定後悔成本很高。

- **子公司（subsidiary，100% 外資有限公司）** — 獨立台灣法人。預設選擇，適合要在地招募、要在台灣產生營收、要把 IP 跟母公司隔離的外商。實務上實收資本落在 NT$50 萬–200 萬（依招募規模與銀行而定）。
- **分公司（branch）** — 外國母公司的法律延伸。設立較快、無最低資本門檻，但母公司直接承擔責任。常見於外商銀行、航空、專業事務所。
- **辦事處（representative office）** — 非營業聯絡單位。不能開發票、不能銷售。只在 pre-commit 驗證或供應商協調階段使用。

更完整的比較見 [外商進入台灣市場完整指南](/insights/taiwan-market-entry-guide#外商可用的法人型態)。本份設立指南預設你要設子公司，因為 80%+ 的外商案件都是子公司；分公司流程結構類似，只是少了股東結構這一段。

## 第一步 — 事前核准：名稱預查與 FIA 送件

FIA（外國人投資申請）是公司登記前的法定關卡，由經濟部投審單位負責。{/* ⚠️ VERIFY: 確認最新投審主管機關名稱（投資審議委員會 / 投資審議處）在最近重組後的正式稱呼 */}

### 公司名稱預查

向經濟部送 2–3 個中文公司名稱候選。名稱須符合命名規則（不得與既有公司衝突、不含禁用字、須含法人型態字尾）。典型回應 **3–5 個工作天**。

### 文件清單（FIA 送件用）

- 母公司**設立證明 / 良好存續證明**，須在母國完成公證與驗證
- 母公司**董事會決議**，明確授權設立台灣法人、資本金額、授權代表人 — 須公證與驗證
- 各董事與監察人**身分文件**（護照影本），須公證
- **授權代表人之授權書**，須公證與驗證
- 擬設台灣法人**章程草本**（中文）
- **業務範圍**中文描述，須對應到經濟部標準營業項目代碼
- 資金來源證明（母公司銀行對帳單或同等文件）

### FIA 送件與核准

文件包送至投審機關。非限制性行業、文件完整的標準審查約 **2–4 週**。{/* ⚠️ VERIFY: 確認投審機關公布的最新標準審查工作日數 */} 限制性行業（電信、廣播、特定物流）或陸資案件因跨機關會審，時程明顯拉長。

FIA 核准函是把外資匯入指定資本注入帳戶的法定授權。沒有這份核准函，後續無法啟動。

### FIA 常見被退件的原因

1. **公證層級錯誤** — 公證人權限不足、或缺少在台灣使用所需的領事 / 海牙驗證章。
2. **董事會決議寫得太籠統** — 決議只寫「拓展亞洲」，沒有具名授權台灣法人。
3. **業務範圍措辭觸及限制性行業旗標** — 英文寫好再翻譯不當，會讀起來像電信 / 媒體 / 金融，即使實際業務不是。
4. **陸資分類錯誤** — 沒有揭露母公司端的陸方政府持股比例；Type 1 / 2 / 3 分類誤判。
5. **資本金額在不同文件中不一致** — 董事會決議、FIA 申請書、資本注入計畫的金額必須完全一致。

每次退件典型加 **2–6 週**重作，因為多數修正需要回母國重新公證。

## 第二步 — 資本匯入與會計師簽證

FIA 核准後，母公司將核准金額匯入 FIA 指定的台灣銀行資本注入專戶。銀行出具資本匯入證明。

台灣執業會計師接著做**資本簽證** — 確認資金到位、金額對應 FIA 核准、出具公司登記所需的資本額查核報告。會計師事先就位的情況下，典型時程 **1–2 週**。

資本注入帳戶**不是**公司營運帳戶。公司登記完成後，資本才能從注入帳戶轉到正式營運帳戶。

## 第三步 — 公司登記（經濟部）

備齊 FIA 核准函與會計師資本簽證後，向經濟部商業司辦理公司登記。文件包含章程、董監事任命書、登記地址、業務範圍。

典型處理時程 **1–2 週**。公司於登記日正式成立，取得公司登記證明書。{/* ⚠️ VERIFY: 確認經濟部商業司外資公司設立登記最新規費金額 */}

到這個階段公司有統一編號、有登記地址、有公司負責人 — 但還沒有營運銀行帳戶、沒有國稅局稅籍、沒有勞健保、沒有工作證。

## 第四步 — 稅務登記與帳冊義務

公司登記後（通常一週內）向國稅局辦理稅籍登記。產出：

- **營業稅（加值型）登記**，5%
- **營利事業所得稅**登記，淨所得 20%（未分配盈餘加徵 5%）
- **扣繳稅**登記，非居民支付的基本扣繳率 21%（協定可降）
- **統一發票**領用授權 — 在台灣稅制下，認列營收必須開立統一發票

法定帳冊 — 總帳、明細帳、固定資產登記簿、員工名冊 — 從這一刻起須維護。多數外資公司把帳務外包給會計師事務所；成本明顯低於東京或新加坡的對應服務。

## 第五步 — 銀行開戶（隱形瓶頸）

銀行開戶是每位創辦人都低估的步驟。實務時程是公司登記後 **2–6 週**。慢的關卡：

1. **外籍董事 KYC** — 在反洗錢監管壓力下，台灣銀行對外籍護照董事的盡調強度提高。親臨面談常見，特別是大型商銀。資金來源證明可能要求到董事個人層級，不只公司層級。
2. **實質受益人申報** — 台灣法人之上有多層控股的情況，問卷必須一次填對；改一次就重排隊。
3. **文件翻譯** — 非中英文的母國文件須翻譯與公證。

### 銀行選擇的實務

部分台灣銀行有專屬外商業務部門與雙語客戶經理，部分沒有。銀行選擇要早期就定，因為 FIA 指定的資本注入帳戶會把這層關係綁定至少初期。{/* ⚠️ VERIFY: 未確認各銀行最新外商業務部門能力前，不公開具名推薦 */}

預先對齊的文件包 — KYC 問卷預填、資金來源證明預先翻譯、董事預先 brief 可能面談題目 — 可把 4–6 週壓到約 2 週。

## 第六步 — 工作證與創辦人居留

外籍個人要在台灣法人工作或為其工作，有三條路徑。

### 就業金卡

台灣的旗艦工具：整合**工作許可 + 居留簽證 + 重入境許可 + 居留證**，效期 **1–3 年**。資格分 8 類：科技、經濟、教育、文化藝術、體育、金融、法律、建築。適合外籍創辦人、資深主管、技術主管，只要符合任一類資格（典型門檻包含資深薪資紀錄、專業認證、特定領域具體成就）。金卡持有人**不綁雇主**，營運上是很大的彈性優勢。

### 創業家簽證

給尚未達到金卡資格、但要在台灣創業的外籍創辦人。需符合資本投入門檻、加入指定創新計畫、或具備特定階段募資紀錄等條件之一。{/* ⚠️ VERIFY: 確認國發會公布的最新創業家簽證資格門檻（資本額 / 募資階段 / 加速器計畫） */} 典型效期 1 年，可續。

### 雇主申辦一般工作證

台灣法人為外籍員工申辦的標準路徑。需要台灣法人擔任雇主、薪資高於外籍專業人士最低門檻、具備合格學經歷。典型處理 **3–4 週**。適合法人成立後的外籍員工。

## 端到端實際時程

下表假設非限制性行業、文件齊全、母國公證與策略階段平行。

| 階段 | 序列 / 平行 | 典型時程 |
|---|---|---|
| 策略 + 法人型態 + 業務範圍草擬 | 序列 | 2–4 週 |
| 母國端文件公證 | 與策略平行 | 2–4 週 |
| 公司名稱預查（經濟部） | 序列 | 3–5 個工作天 |
| FIA 送件 → 核准 | 序列 | 2–4 週 |
| 資本匯入 + 會計師簽證 | 序列 | 1–2 週 |
| 公司設立登記（經濟部） | 序列 | 1–2 週 |
| 稅務登記（國稅局） | 序列 | ~1 週 |
| 銀行開戶 | 登記後序列 | 2–6 週 |
| 工作證 / 金卡申請 | 與銀行平行 | 3–4 週 |
| **端到端（啟動到法人完整運作）** | — | **10–12 週** |

兩個具體的加速器：(a) 母國公證與策略階段平行，不要等策略完成才開始公證；(b) 銀行 KYC 文件在公司登記**前**就預先對齊，登記當天就送銀行申請。

## 設立後：持續性合規行事曆

設立完成不是法務終點。台灣法人前 12 個月有可預期的合規循環：

| 頻率 | 項目 | 備註 |
|---|---|---|
| 每月（次月 15 日前） | 營業稅（5% 加值型）申報 | 向國稅局申報，國稅局網站 e 化 |
| 每月 | 勞健保提撥 | 雇主端負擔約薪資的 15% |
| 每月 / 每次支付 | 扣繳稅申報 | 給非居民的支付（權利金、勞務、股利） |
| 每年（5 月） | 營利事業所得稅申報 | 淨所得 20%、未分配盈餘加徵 5% |
| 每年 | 董監事揭露更新 | 異動時 |
| 視情況 | 增資 / 減資 / 股權移轉申報 | 外資公司須辦 FIA 變更 |
| 每年 | 簽證財報 | 超過特定營收 / 資本門檻時強制 {/* ⚠️ VERIFY: 確認最新強制簽證財報的營收 / 資本門檻 */} |

多數外資公司把例行合規外包給會計師事務所，月費明顯低於東京、首爾、新加坡同等服務。

## DIY 與找顧問的成本取捨

設立流程是公開資料。外商技術上可以靠雙語代辦加在地會計師完成。誠實的問題是：市場進入顧問比代辦多了什麼？

| 決策 | 文件代辦 | 市場進入顧問 |
|---|---|---|
| 法人型態（子公司 / 分公司 / 辦事處） | 執行你選的 | 依營收 / 招募 / IP 計畫建議 |
| 資本額 | 執行你給的數字 | 模擬銀行 KYC 門檻、工作證要求、招募 runway |
| 業務範圍措辭 | 翻譯你給的 | 設計避開限制性行業旗標、保留未來彈性 |
| 銀行選擇 | 「我們對接幾家」 | 知道哪家銀行的外商部門配哪種董事 profile |
| 工作證路徑（金卡 / 創業家 / 一般） | 執行你選的 | 依 profile + 時程路由 |
| 行業特許（TFDA、NCC、金管會） | 轉介 | 納入時程協調 |
| 設立後 GTM（招募、通路、PR） | 範圍外 | 同一個案 |

答案因公司而異。有經驗的亞太團隊、設立過、有清楚 PMF 假設的公司，可以壓縮顧問層。沒有在地關係、第一次進這個區域的公司，幾乎都能從避開的錯誤裡回收顧問費 — 特別是法人型態、銀行選擇、前三位員工這三個地方。

## 設立階段常見踩雷

1. **業務範圍還沒定就送 FIA** — 送件後改範圍須重做母國董事會決議公證。
2. **文件公證完才發現中文名稱預查不過** — 名稱出現在公證的章程上；退件就得重新公證。
3. **資本額設太低過不了銀行 KYC** — 銀行看資本要對應宣告的業務範圍；NT$10 萬資本配「進口與經銷」的業務範圍會被當空殼。
4. **低估董事 KYC** — 非亞洲護照、資金歷史複雜的董事，要預期銀行更深的盡調。
5. **忘記登記地址** — 登記當天就要有實體地址；虛擬辦公室地址即使經濟部接受，銀行有時會有疑慮。
6. **行業特許等到登記後才處理** — TFDA、NCC、金管會、進口許可的前置期長，應該與公司登記同步啟動，不是登記後才開始。
7. **勞保還沒登記就僱第一個員工** — 會被裁罰、勞工局後續會找麻煩。
8. **把工作證當事後再說** — 金卡與創業家簽證可以與公司設立平行啟動；事後再做會多耗數個月的創辦人有效在地時間。
